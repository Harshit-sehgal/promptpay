counts, gate totals, Docker diagnosis, deployment status, and provider
configuration drifted from the live source and could mislead a release
decision.

Use these current sources instead:

- `AGENTS.md`, **Open Items (external — operator / infra / product / legal,
  NOT code)**, for the live residual blocker register.
- `LAUNCH_PLAN.md` for sequencing and launch phases.
- `docs/ops/deployment-checklist.md` for the cold-start and deployment

As always, source and fresh gate output outrank narrative status text.
